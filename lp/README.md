# Material für die Lehrperson

Dieses Verzeichnis ist bewusst **nicht** in der Navigation der Website. Es liegt
im selben Repo, damit es zusammen mit dem Material gepflegt wird.

Pro Modul ein Blatt mit:

- Diagnosefragen für das Gespräch
- typische Fehlvorstellungen und wie man sie aufdeckt
- Tafelbild-Vorschlag
- LP-Wert des Moduls (hoch / mittel / niedrig)
